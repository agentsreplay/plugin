---
description: Show the QR code that pairs your iPhone with Agents Replay
---
Call the `pair` tool of the agents-replay MCP server, with no arguments. Then tell the user, in one or two short lines,
to open Agents Replay on their iPhone and scan the code (the iPhone must be on the same Wi‑Fi as this Mac). The code
also opened in Preview on the Mac. Don't describe the image, don't read its contents back, and don't save it anywhere:
anyone holding the code can read the user's agent history.
